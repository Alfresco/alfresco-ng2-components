# Changelog

This release contains no library changes. The published packages are functionally
identical to v8.0.2 and differ only by their version number.

The commits in this range rework the GitHub Actions release pipeline. They carry the
message `Release 8.0.3 - Fix PNG signature images in PDF viewer`, but none of them
touch library code; that fix shipped in
[v8.0.4](RelNote-8.0.4.md).
